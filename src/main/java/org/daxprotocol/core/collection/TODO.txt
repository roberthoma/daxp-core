🔹 Znaczenie semantyczne

Single
    dokładnie jedna wartość
    domyślność dla pól

List
    uporządkowana kolekcja
    duplikaty dozwolone

mapuje się na:
    array
    list
    vector

Set
    nieuporządkowana
    unikalne elementy

semantyka > struktura

Map
    klucz → wartość
    klucz ma własny typ


klucz nie musi być stringiem

Tuple

    uporządkowany zbiór różnych typów
    struktura pozycyjna

✅ bardzo przydatne do:

    wyników
    sygnatur
    interfejsów dynamicznych

Propozycja mapowania atrybutów kolekcji

Aby to było spójne, Twoje tagi atrybutów ($:21, :22, itd.) powinny działać jak przełączniki (switches):
Tag	Atrybut	Opis (Logic)	Odpowiednik w programowaniu
$:21	Allow Duplicates	True (default) / False	False zamienia kolekcję w Set
$:22	Has Keys	Wskazuje, że element składa się z pary Key=Value	Zamienia kolekcję w Map
$:23	Ordered	Czy kolejność wstawiania ma znaczenie?	True to List, False to Bag
$:24	Navigable	Czy element zna swojego sąsiada (następnik/poprzednik)?	Tworzy Linked List lub Graph
$:25	Is Dictionary	Czy ta kolekcja służy jako źródło prawdy dla innych pól?	Twoje LOV / Dictionary


+ Wstazanie typu jaki jest podstawa kolekcji .
